# Sketch ticket (HITL)

A rough, concrete thing to react to, when "what could it look like?" is the question.

1. **Claim** the ticket.
2. **Make it rough.** In Figma, call the Skill tool with "explore-variants" for a few radically different takes. Outside Figma, a wireframe or a rough HTML page will do. Low fidelity keeps the reaction on the idea, not the polish.
3. **Show it** and ask for the user's reaction in one round ([grilling.md](grilling.md)): which take, what's missing, what it ruled out.
4. **Resolve** when the user names what the sketch taught them. The findings note links the sketch and records the reaction and what it decided.
