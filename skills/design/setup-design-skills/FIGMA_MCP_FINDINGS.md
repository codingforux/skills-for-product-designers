# Figma MCP findings

What this team has learned about working through the Figma MCP: limits, traps and workarounds. The figma-writes skill reads it before every Figma job, and agent-retro adds to it. It starts empty.

## Rules

- **One finding per bullet**: what happens, and what to do instead.
- **Only what the skills don't already say.**
- **Group findings under subheadings** (for example Reading, Writing, Reports) once there are enough to need them.
- **Keep the user in the loop.** Never change this file silently. Propose each new or changed finding to the user, and write it only once they agree.
