# Glossary

The product's own words. Use them in briefs, tickets, frame and layer names, and copy.

## Language

**Workspace**:
The shared space a team works in.
_Avoid_: Account, org

## Rules

- **Be opinionated.** When several words exist for the same thing, pick the best one and list the others under `_Avoid_`.
- **Keep definitions tight.** One or two sentences. Define what it IS, not what it does.
- **Only this product's words.** General UI words (button, modal, toast) don't belong, even if the product uses them everywhere.
- **Group terms under subheadings** when natural clusters emerge.
- **Keep the user in the loop.** Never change this file silently. Propose each new term, changed definition or new `_Avoid_` word to the user, and write it only once they agree.

If the word you need isn't here, that's a signal: either you're inventing language the product doesn't use (reconsider) or there's a real gap (propose a new term).
