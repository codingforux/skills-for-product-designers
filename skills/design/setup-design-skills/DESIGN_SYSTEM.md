# Design system

How this product uses its library. Designers read it when picking components, and `design-review` checks frames against it. It starts empty; entries are added as the team makes decisions.

## Rules

- **Only decisions this product made.** Don't restate the library's own docs.
- **Name things exactly as the library does.**
- **Group entries under subheadings** once there are enough to need them, chosen by the team.
- **Keep the user in the loop.** Never change this file silently. Propose each new or changed entry to the user, and write it only once they agree.
