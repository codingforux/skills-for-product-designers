# Labels

The design skills speak in terms of five roles. This file maps those roles to the actual label strings used in this product's issue tracker.

| Role              | Label in our tracker | Meaning                                                            |
| ----------------- | -------------------- | ------------------------------------------------------------------ |
| `design-brief`    | `design-brief`       | A design brief: the parent issue of its questions and tickets      |
| `needs-alignment` | `needs-alignment`    | A question only your team can answer; closed with the answer recorded |
| `ready-for-agent` | `ready-for-agent`    | A ticket fully specified, ready for an agent to design             |
| `ready-for-human` | `ready-for-human`    | A ticket only a person can design                                  |
| `ready-for-review`| `ready-for-review`   | A designed ticket waiting for the user's review                    |

When a skill mentions a role (e.g. "label it `needs-alignment`"), use the corresponding label string from this table.

Edit the right-hand column to match whatever vocabulary you actually use.
