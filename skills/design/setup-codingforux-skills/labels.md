# Labels

The UX skills speak in terms of these roles. This file maps those roles to the actual label strings used in this product's issue tracker.

| Role                        | Label in our tracker        | Meaning                                                               |
| --------------------------- | --------------------------- | --------------------------------------------------------------------- |
| `ux-brief`                  | `ux-brief`                  | A UX brief: the parent issue of its questions and tickets             |
| `needs-alignment`           | `needs-alignment`           | A question only your team can answer; closed with the answer recorded |
| `ready-for-ux-agent`        | `ready-for-ux-agent`        | A ticket in an open pass, ready for a UX agent                        |
| `ready-for-designer`        | `ready-for-designer`        | A ticket only a person can design                                     |
| `ready-for-designer-review` | `ready-for-designer-review` | A designed ticket waiting for the user's review                       |
| `ux-exploration`            | `ux-exploration`            | An exploration map: the parent issue of its question tickets          |
| `explore:research`          | `explore:research`          | An exploration ticket answered from public sources                    |
| `explore:pattern-scan`      | `explore:pattern-scan`      | An exploration ticket comparing how other products solve a problem    |
| `explore:interview`         | `explore:interview`         | An exploration ticket answered by talking to coworkers or customers   |
| `explore:task`              | `explore:task`              | Legwork that unblocks an exploration question                         |
| `explore:sketch`            | `explore:sketch`            | A rough artifact to react to                                          |
| `explore:grilling`          | `explore:grilling`          | A decision only the user can make                                     |

When a skill mentions a role (e.g. "label it `needs-alignment`"), use the corresponding label string from this table.

Edit the right-hand column to match whatever vocabulary you actually use.
